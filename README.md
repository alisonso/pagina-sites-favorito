# Meus sites favoritos

Página web em HTML com 5 sites favoritos: nome, imagem e link de cada um.

## Sites

YouTube, GitHub, Instagram, Xbox e Steam.

## Como executar

Baixe o repositório e abra o arquivo `index.html` no navegador.

## Arquivos

- `index.html`: página com o código comentado
- `*.png`: imagens dos sites
- `captura-codigo.png` e `captura-execucao.png`: capturas de tela
